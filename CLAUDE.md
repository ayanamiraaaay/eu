# LazioEU — правила работы с репозиторием

Сайт консалтинга LazioEU (прямые гранты ЕС для компаний в Италии).
Живой сайт: https://ayanamiraaaay.github.io/eu/ (GitHub Pages, «Deploy from a branch»: main, / root).

## Деплой — автоматический
- Любая доработка сайта: правим файлы → `git commit` → `git push origin main`. GitHub Pages сам обновляет сайт за 1–2 минуты. Владелец проекта (Юра) просил делать это **автоматически, без отдельного вопроса**, для обычных правок.
- Спрашивать перед пушем, только если правка необратима или рискованна: удаление страниц, смена домена, крупная переделка структуры.
- Перед пушем: проверить страницы в браузере (Playwright, десктоп 1440 и телефон 390), без горизонтальной прокрутки, без ошибок в консоли.
- Сборки нет: чистый HTML/CSS/JS. Не добавлять npm-зависимости и сборщики без согласования.

## Структура
- `index.html`, `bandi.html`, `privacy.html` — итальянский (основной язык)
- `en/index.html`, `en/grants.html`, `en/privacy.html` — английский (аудитория: иностранные владельцы итальянских компаний)
- `assets/site.css`, `assets/site.js`, `assets/favicon.svg`; `404.html` (использует `<base href="/eu/">` — поменять при подключении своего домена); `.nojekyll`
- Любую правку текста вносить в IT и EN версии одновременно.
- Русская версия существует только как рабочая копия на холсте Design, на сайт не идёт.

## Безопасность
- CSP в `<meta>` на каждой странице: никаких inline-скриптов и inline-стилей (`style="..."`), только классы из `site.css` и код в `site.js`.
- Без сторонних скриптов, cookie и аналитики. Если появится аналитика → нужен cookie-баннер по правилам Garante.
- Шрифты — Bunny Fonts (ЕС), не Google Fonts.
- Форма: открывает почтовую программу (mailto), на сайте данные не хранятся.

## Контент — правила
- Стандарт каждой страницы: 10 вопросов клиента (документ standard-10-voprosov в проекте Claude).
- Никаких выдуманных цифр, отзывов, кейсов, цен, названий конкурсов и дедлайнов. Нет данных — блок не показываем (заглушки только в макетах, не на сайте).
- Не обещать одобрение гранта. Не называть себя avvocati / studio legale. Не использовать флаг/эмблему ЕС.
- Стиль: аккуратно, строго, информативно, для массового взрослого посетителя. Не «огромный красивый лендинг»: светлые секции, тёмные только шапка и футер, заголовки h1 44px / h2 34px, отступы секций 72px, база текста 18px, высокий контраст, без капслока и жаргона, кнопки ≥ 44px, без наложений и «плавающих» карточек.
- Порядок главной: первый экран (кто мы + фото) → ключевые факты → Кто мы (фото консультанта, компетенции) → Услуги (что входит) → Для кого → Как работаем → Цены и гарантии → FAQ → Контакты.
- Фото: только свободные лицензии (Unsplash/Pexels) или фото клиента. Стоковых людей НЕ подписывать как команду LazioEU. Хранить в `assets/img/`, формат WebP/JPEG ≤ 200 КБ, с width/height и alt.

## До публичного запуска (сейчас стоит noindex)
Нужно от клиента: P.IVA и юр. данные (обязательно в футере), телефон/WhatsApp/адрес/часы, цены, кейсы с согласием, команда, срок ответа (на сайте 48 ч — подтвердить), почта на своём домене.
После этого: убрать `noindex` со всех страниц, добавить canonical/hreflang с полным доменом, sitemap.xml.
